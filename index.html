Human-Centered Design for Mobile Computing (HCDD 340)

Westgate Bldg, E206 TuTh, 4:35 – 5:50pm

Overview

This course will provide a hands-on introduction to different methods and tools for designing and developing mobile systems.

Toward this goal, the course will focus on progressive web apps (PWA)

The course will follow a learning-by-doing approach through different class activities, assignments, and a final project.
